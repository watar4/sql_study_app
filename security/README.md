# Supabase RLSの確認・配備

1. プロジェクト管理者としてSQL Editorで `verify-rls.sql` を実行し、実際のRLS状態・ポリシーとuser_id列を確認します。
2. `owner-policies.sql` を確認して適用します。トランザクション内で2テーブルだけを対象にし、既存の別名ポリシーを削除せず、restrictiveな所有者制限を追加します。所有者にはpermissiveポリシーでアクセスを許可します。サービスロールや管理者のBYPASSRLSは変更しません。
3. 未認証のアクセス拒否、ユーザーAからBの行へのSELECT/INSERT/UPDATE/DELETE拒否、本人の操作成功を、別々の利用者で確認します。

このSQLはアプリ公開時には自動実行されません。公開用Supabaseキーにはポリシー管理権限がないため、管理者による配備と実際の権限試験が必要です。ここで対象にしていないテーブルも別途確認してください。
